# Исследовательское тестирование раздела «Новостройки» Wildberries

## Описание

Проект посвящён **исследовательскому ручному тестированию** раздела «Новостройки» сайта Wildberries.

В рамках работы проведена декомпозиция интерфейса и основных пользовательских сценариев раздела. Для каждого элемента и действия определялось ожидаемое поведение интерфейса и формировались соответствующие проверки.

Проект состоит из двух частей:

- дерево проверок раздела в **Miro**;
- подробные тест-кейсы для панели фильтров в формате **PDF**.

## Тестовая документация

### 1. Дерево проверок

Интерактивная карта проверок раздела, выполненная в Miro.

Включает:

- **112 блоков классификации проверок**;
- **160 детализированных функциональных проверок** ожидаемого поведения элементов интерфейса;
- **26 smoke-проверок** основных функций раздела;
- **39 нефункциональных проверок**, охватывающих адаптивность, кроссбраузерность, совместимость, отображение и удобство использования.

Функциональные проверки описывают ожидаемое поведение элементов при конкретных действиях пользователя.

Например:

- при выборе города изменяется название выбранного города и список доступных предложений;
- города без предложений отображаются как неактивные;
- при вводе поискового запроса корректируется список городов;
- при отсутствии результатов отображается сообщение об отсутствии совпадений;
- при прокрутке списка загружается следующая партия городов.

**Miro:**  
[[ССЫЛКА НА MIRO](https://miro.com/app/board/uXjVHIEmVyc=/?share_link_id=751415105365)]

---

### 2. Тест-кейсы панели фильтров

Отдельно проведено детальное тестирование панели фильтров.

Подготовлено **17 позитивных и негативных тест-кейсов**, охватывающих основные сценарии работы панели.

Каждый тест-кейс содержит:

- тестовые данные;
- последовательность шагов;
- ожидаемые результаты;
- тип сценария: позитивный или негативный.

**Документ:**  
`Test_Cases/Wildberries_Realty_Filter_Panel_Test_Cases.pdf`
